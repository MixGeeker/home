# 自建房装修设计

9.0 × 10.0 m 六层自建房（图纸：《住宅方案 6a》）。

- `index.html`：整栋房子的 3D 模型，直接用浏览器打开即可（需联网加载 three.js）。可按楼层剖切，显示房间名称和净面积。
- `model/house.html`：同一模型的页面源码。

## 楼层

| 楼层 | 标高 | 层高 | 功能 |
|---|---|---|---|
| 首层 | ±0.000 | 3.8 | 车库、门厅、储物间、卫生间 |
| 二层 | +3.800 | 3.2 | 客厅、餐厅、厨房、卫生间 |
| 三至五层 | +7.000 / +10.200 / +13.400 | 3.2 | 两卧两卫、阳台 |
| 六层 | +16.600 | 3.6 | 露台、卫生间、楼梯间 |
| 屋顶 | +20.200 | 0.5 | 顶部构架 |

## 建模说明

- 墙体、柱、楼梯、电梯和房间按平面图尺寸定位；门窗宽度和窗台高度按立面图比例估算。
- 首层图纸里的楼梯和卫生间位置有重叠，模型里把卫生间放在楼梯平台下方（净高约 2.2 m）。
- 家具只是示意。

## 四楼：一室套房（业主自住）

- **衣帽卫浴洗衣一体区**（左半边，约 26 ㎡，含阳台）：从后往前依次是淋浴（原浴缸位置）→ 马桶 → 双台盆 → 衣帽间（左墙 4 m 整排衣柜 + 隔墙侧衣柜 + 换衣凳）→ 洗衣阳台（洗衣机和烘干机叠放、洗衣池、晾衣杆）。阳台只从这个区进出。
- **卧室 + 影音区**（约 28 ㎡）：床头靠隔墙，床边一扇门直通衣帽间；85 寸电视挂在客卫外墙，沙发正对，视距约 2.6 m；临街窗前 2 m 书桌。
- **玄关 · 手办长廊**：入户门对电梯厅，左侧 1.8 m 到顶玻璃手办柜，右侧鞋柜 + 矮展示柜；书桌旁再加一组到顶手办柜。
- **客卫**：保留原卫生间 B，门改开向玄关，客人不用穿过卧室。
- 注意：台盆移到电梯井墙边、洗衣机放阳台，都需要新做排水和防水；衣帽间紧挨湿区，要做好挡水和通风除湿。

## 三楼：父母房中房

- 父亲打鼾，父母分房睡：两间卧室各带独立卫生间，中间墙上开一扇隔音互通门（约 0.85 m 宽），夜里有事可以直接过去。
- 两间卧室之间的墙加厚到约 20 cm，做隔音棉 + 双层石膏板；互通门用实木隔音门并加门底密封条。
- 父母同住，入户不分开：去掉小过道和两扇分开的卧室门，电梯厅只开一扇门进卧室 A，卧室 B 经隔音互通门进出。
- 修正：三、五楼原模型过道入口漏开了门，现已补上。

## 门不对床（业主要求）

- 三楼互通门移到床尾一侧的墙角（不在床的正前方），卧室 A 的床往阳台方向挪，衣柜移到互通门旁边。
- 三、五楼卫生间 B 的门从正对床的那面墙改到侧墙。
- 四楼入户门顺着手办长廊会看到床侧，加一组玄关屏风柜（下柜 + 上玻璃）挡住视线。
- 三楼卫生间 B 往左扩到隔墙边，卧室 B 的墙拉直（卫生间约 7.0 ㎡，卧室 B 约 19.2 ㎡）。门开在左下角靠互通门一侧，不对床。布置：双台盆靠后墙 → 马桶 → 1.7 m 浴缸靠右墙（窗在浴缸上方），浴缸可带淋浴挡水玻璃。
- 三楼卧室 B 临街窗下放 1.6 m × 0.6 m 电脑桌 + 电脑椅（桌面到床尾约 0.9 m 通道）。
